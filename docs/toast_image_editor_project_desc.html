Professional image editing directly within Drupal - no external software needed. Perfect for enhancing any image including AI-generated content with a full-featured editor that creates proper media revisions.

You need Toast Image Editor if

  • You're using AI-generated images and need to fine-tune them in your workflow
  • Your content editors need to crop, resize, or adjust images without leaving Drupal
  • You want to maintain image revision history for rollback capability
  • You need to add text overlays, watermarks, or annotations to any images

Features

Photo Manipulation

  • Crop: Free crop or aspect ratio presets (16:9, 4:3, 1:1, custom)
  • Flip & Rotation: Horizontal/vertical flip, 90° rotations, custom angles
  • Drawing: Free drawing with customizable brush size and colors
  • Shapes: Rectangle, circle, triangle with fill and stroke options
  • Icons: Built-in icon library for annotations
  • Text: Add text overlays with font, size, color, and alignment control
  • Mask & Filters: Apply masks and professional image filters

Powerful Filter Functions

  • Classic Filters: Grayscale, Sepia, Invert, Blur, Sharpen
  • Advanced Effects: Emboss, Remove White, Pixelate, Noise
  • Color Adjustments: Brightness, Contrast, Tint, Color Filter
  • Blend Modes: Multiply, Screen, Difference, Lighten

How to Use Toast Image Editor

Once installed, Toast Image Editor integrates directly into your Drupal media edit forms:

Editing Images

  1. Go to Content → Media (/admin/content/media)
  2. Click "Edit" on any image media item
  3. Scroll down to the "Image Editor" section
  4. Use the editor tools to crop, draw, add text, apply filters, etc.
  5. Click "Save" to save your changes and create a new revision

Quick Access

  • From content editing: When editing content with image fields, click "Edit" on any image
  • Direct editing: The editor appears automatically on image media edit forms
  • Immediate availability: No separate interface - editing happens within the standard media form

Getting Started

  1. Install with composer require drupal/toast_image_editor
  2. Run drush en toast_image_editor
  3. Configure at /admin/config/media/toast-image-editor
  4. Set permissions at /admin/people/permissions#module-toast_image_editor
  5. Start editing images immediately through the Media library
