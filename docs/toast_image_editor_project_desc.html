How to Use Toast Image Editor

Once installed, Toast Image Editor integrates directly into your Drupal media edit forms:

Editing Images

  1. Go to Content → Media (/admin/content/media)
  2. Click "Edit" on any image media item
  3. Scroll down to the "Image Editor" section
  4. Use the editor tools to crop, draw, add text, apply filters, etc.
  5. Click "Save" to save your changes and create a new revision

Quick Access

  • From content editing: When editing content with image fields, click "Edit" on any image
  • Direct editing: The editor appears automatically on image media edit forms
  • Immediate availability: No separate interface - editing happens within the standard media form

Getting Started

  1. Install with composer require drupal/toast_image_editor
  2. Run drush en toast_image_editor
  3. Configure at /admin/config/media/toast-image-editor
  4. Set permissions at /admin/people/permissions#module-toast_image_editor
  5. Start editing images immediately through the Media library

FAQ

Does Toast Image Editor create Drupal media revisions?

Yes. Every edit creates a proper media revision in Drupal's revision system. This means you can review, compare, and roll back any image change using standard Drupal revision tools or the Diff module. The full editing history is preserved for audit and rollback purposes.

Does Toast Image Editor work with AI-generated images?

Yes. The editor works with any image in your Drupal media library regardless of how it was created. AI-generated images from DXPR Builder or other tools can be cropped, filtered, annotated, or adjusted directly within Drupal without downloading and re-uploading through external software.

Which image editing operations are supported?

The editor includes crop (free and preset aspect ratios), flip and rotation (including custom angles), free drawing with brush controls, shape overlays (rectangle, circle, triangle), text overlays with font and colour control, a built-in icon library, mask and filter effects, and colour adjustments (brightness, contrast, tint). All operations are non-destructive until saved.
